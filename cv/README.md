# CV folder

Place your real CV here as exactly:

    Melvin-Tabitha-CV.pdf

The site checks for this file automatically (see `js/main.js`): as soon as it
exists, the "View CV" buttons appear in the header and hero on every page.
Until then they stay hidden, so the site never shows a download button that
points at a missing file.

Keep the filename exactly as above — it is referenced from every page and is
what visitors will see when they download it.
